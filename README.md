Дашборд продаж: анализ маржинальности по категориям и скидкам
Выводы:
Электроника даёт 62% выручки и 92,5% прибыли (маржа 11,2%). Мебель даёт 32% выручки, но только 0,8% прибыли (маржа 0,2%).
Скидки снижают маржу в каждой категории. Порог безубыточности: мебель ~6-7%, канцелярия ~20%, электроника ~25%.
Рекомендация: ввести лимиты скидок по категориям (мебель до 5%, электроника и канцелярия до 10%) и пересмотреть закупочные цены на мебель.
