# Анализ маржинальности: категории и скидки

## Вопрос

Какие категории и уровни скидок приносят прибыль, а какие её съедают?

## Данные

Синтетические данные: 10 000 заказов за 2023-2024 годы, 3 категории товаров, 6 регионов Беларуси, 3 сегмента клиентов. Данные генерируются скриптом `gen_data.py` с фиксированным seed, поэтому результат воспроизводится один в один. В данные намеренно добавлены пропуски и дубликаты для практики очистки.

## Как воспроизвести

```
pip install pandas numpy matplotlib
python gen_data.py
python check.py
```

## Ключевые показатели

## Маржа по категориям и скидкам (%)

| Категория | 0% | 5% | 10% | 20% | 30% |
|---|---|---|---|---|---|
| Электроника | 14,9 | 12,0 | 8,8 | 2,9 | -2,6 |
| Канцелярия | 11,9 | 9,0 | 6,0 | 0,2 | -5,9 |
| Мебель | 4,0 | 1,1 | -1,8 | -8,0 | -14,3 |

## Выводы

1. **Электроника** даёт 62% выручки и 92,5% прибыли (маржа 11,2%). **Мебель** даёт 32% выручки, но только 0,8% прибыли (маржа 0,2%).
2. Скидки снижают маржу в каждой категории. **Порог безубыточности:** мебель около 6-7%, канцелярия около 20%, электроника около 25%.
3. На скидках 20% и 30% суммарный убыток около 52 тыс. при обороте 1,7 млн.

## Рекомендации

- Ввести лимиты скидок по категориям: мебель до 5%, электроника и канцелярия до 10%.
- Пересмотреть закупочные цены на мебель: даже без скидок её маржа всего 4%.
